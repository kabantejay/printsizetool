# PrintSizeTool.github.io
Print Image at Exact Size - Split Across Multiple Pages to PDF

EXACT SIZE TILED PDF MAKER
==========================

Upload all files in this folder to the public directory of your website.
The app is fully static and does not need PHP or a database.

Main file:
  index.html

Dependency:
  jsPDF 4.2.1 is loaded from jsDelivr CDN.
  Images stay in the visitor's browser and are not uploaded to your server.

Recommended deployment:
1. Create a folder such as /print-image-actual-size/
2. Upload index.html, favicon.svg, social-preview.svg, robots.txt and sitemap.xml
3. Replace https://example.com/ in sitemap.xml and robots.txt with your real domain and path.
4. Add the final URL to Google Search Console and submit sitemap.xml.
5. Keep the visible English explanatory text on the page: it targets useful long-tail searches without keyword stuffing.

Important print instruction for users:
  Print the generated PDF at 100% / Actual size.
  Do not use Fit, Shrink, Scale to fit or Borderless enlargement.

Browser support:
  Current Chrome, Edge, Firefox and Safari.
